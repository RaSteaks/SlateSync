# SM-01 — SwiftPM and Xcode foundation

Status: **REVIEW_READY (implementation complete; formal admission pending)**

Create the five SwiftPM libraries, Xcode App/Unit/UI Test targets, shared scheme,
test plan, native WindowGroup/Settings shell, deterministic build-and-run script
and Codex Run action. Gate: SwiftPM and Xcode build/tests pass and the app can be
run and debugged from Xcode.

## Delivered

- `Package.swift` exposes Domain, Persistence, Media, Workflow and UI libraries
  with Swift 6 strict concurrency and macOS 15.0.
- `SlateSync.xcodeproj` contains App, Unit Test and UI Test targets; the shared
  `SlateSync` Scheme maps Run/Analyze to Debug and Profile/Archive to Release.
- `SlateSync.xctestplan` runs one isolated Library composition test and one real
  app-launch UI test. UI tests pass `SLATESYNC_TEST_ROOT` and never use live data.
- Debug builds use the active architecture, DWARF and `-Onone` for breakpoints.
  Release/Archive use `ONLY_ACTIVE_ARCH = NO` and build arm64 plus x86_64.
- The native shell has WindowGroup, Settings, sidebar navigation, project-library
  empty/error states and the existing layered Icon Composer application icon.
- `script/build_and_run.sh` and `.codex/environments/environment.toml` provide a
  deterministic Run entry with `--debug`, `--release`, `--logs`, `--telemetry`
  and `--verify`.
