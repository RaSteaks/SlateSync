# SM-02 — macOS-only platform contract

Remove Windows build configuration, documentation and conditional behavior.
Move CI and release authority to macOS. Gate: no current entry point claims or
produces a Windows or Linux application.

## Implementation notes (uncommitted; review pending)

- Current development, native run, OCR setup, Electron packaging and release
  entrypoints are guarded to macOS; non-macOS builder aliases fail before an
  application target is invoked.
- `electron-builder.yml` contains only macOS DMG/ZIP targets for arm64 and x86_64;
  GitHub CI and release jobs run on macOS and invoke the shared
  `./script/phase_gate.sh SM-02` entrypoint.
- `script/tests/sm02_platform_contract.mjs` performs behavioral checks for the
  npm entrypoints, builder/workflow structure, platform rejection and retained
  Electron/React/Node historical baseline. It is executed as a required SM-02
  Gate check, while the existing SwiftPM/Xcode/archive checks remain shared.
- `CURRENT_STATE.json` remains unchanged with SM-01 COMPLETE. This package is
  not marked PASS or COMPLETE, and no Owner approval is recorded here.
