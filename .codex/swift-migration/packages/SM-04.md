# SM-04 — SQLite and Project Library

Port the v1 Library/project/task/scenario stores to system SQLite3 with the exact
schema, pragmas, snapshots and deletion safety. Gate: a copied v1 Library survives
read/write/close/reopen without semantic drift.

## Tracked findings from earlier phases

- `SQLiteDatabase.rows` must distinguish terminal `SQLITE_DONE` from
  `SQLITE_BUSY`, `SQLITE_ERROR`, and other step failures instead of returning a
  partial result. Add a regression test that forces a row-step failure and
  verifies the stable `SlateSyncError` mapping.
