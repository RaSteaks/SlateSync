## Resolved implementation gaps

- The three UI failures were separated into product and locator causes. The
  `CommandGroup(replacing: .saveItem)` Close action had lost scene ownership;
  it now routes through `NSApp.keyWindow?.performClose(nil)`, so the window
  delegate can drain/approve the close while auxiliary Settings windows close
  normally.
- Multiline macOS Form fields and Pickers exposed their titles as sibling static
  elements. Workspace, project settings, project creation, and global appearance/
  density controls now expose explicit Chinese accessibility labels and stable IDs.
- Project creation and the Chinese reopen flow use focused keyboard commands and
  the explicit Open action, avoiding duplicated SwiftUI toolbar children while
  retaining end-to-end keyboard coverage.
- The native CSV surface now asserts table/header/cell semantics. A separately
  gated visible-window harness records real display cadence; ordinary SwiftPM
  runs keep that window test skipped.
- The formal Gate preserves raw Xcode XCTest PASS lines before generating
  acceptance evidence. The test progress probe uses Swift 6 `Mutex`; the
  window delegate's synchronous forwarding boundary uses balanced retained
  Objective-C ownership without `@unchecked Sendable`.
