## Implemented boundary

Domain owns immutable Provider, transport, probe, recognition, error and legacy
TakeStatus values plus the narrow credential/clock/transport/persistence
protocols. Persistence keeps credentials in `KeychainCredentialStore` and
routes recognition project/task/diagnostic activity through `ProjectRuntime`
leases. No public Provider/model/progress/error DTO contains a credential,
Authorization header, raw price or aggregate cost.

Workflow owns the five built-in/legacy/custom Provider routes, curated physical
model mapping, revision-aware registration, five-minute discovery cache,
synthetic visual capability probe, ephemeral URLSession transport, Responses
and Chat Completions payloads, structured-output fallback, exact prompts and
schemas, tolerant normalization, continuity repairs, high-accuracy
primary/audit/review stages, bounded page fan-out, and the OCR-first coordinator.
The coordinator composes SM-06 media/OCR, Scenario selection, UTF-8 request
budgeting, monotonic progress, fail-fast global concurrency, project
cancellation, task/diagnostic persistence, and idempotent close/drain.

Original PDF payloads are rejected before media, OCR, network or persistence
side effects. Credentials are read only while the transport creates headers.
Only timeout failures retry; provider, authentication, parsing, connection and
cancellation failures do not. Cross-origin redirects are followed with
Authorization stripped, response bodies are capped at 16 MiB, canceled probe
batches drain and do not publish stale capability state, and failed page groups
cancel and await siblings before returning.

Workspace/settings/log/help UI remains SM-08 work. Packaging, notarization,
distribution and removal of retained Electron sources remain SM-09 work. No
SQLite schema, Project Library v1, Scenario v1 fingerprint, Resolve CSV byte
