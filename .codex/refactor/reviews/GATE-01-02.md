## Compiled Preload Decision

`IP-0102-PRELOAD-001` is **ACCEPTED AND CLOSED FOR GATE 01-02**.
BrowserWindow loading the single compiled CommonJS
`out/preload/index.cjs` directly is the correct sandbox-preserving boundary.
Electron's sandboxed Preload cannot use `electron/preload.cjs` to `require` a
second application-local module; retaining that failed bootstrap would create
two executable paths or duplicate bridge code. The compiled entry preserves
`sandbox: true`, context isolation, sole `slateSync`, raw-channel confinement,
and test-import purity. `electron/preload.cjs` is an explicit non-executable
transition marker and not a second runtime abstraction.
