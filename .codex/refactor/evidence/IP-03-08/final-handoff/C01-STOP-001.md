# C01 Stop Condition — Authority Verifier Phase Conflict

Recorded: 2026-08-21 (Asia/Shanghai)

## Finding

The C01 package requires the machine-readable authority phase to change to
`IP-03-08_READY_FOR_FINAL_REVIEW` only after all acceptance items pass, and it
also requires `node .codex/refactor/verify-current-state.mjs` to pass again
after that reconciliation. The existing verifier contains the following
strict assertion:

```js
assert.equal(state.phase, "IP-03-08_READY_FOR_CONTINUOUS_IMPLEMENTATION");
```

Therefore the required final phase makes the required final verifier exit
non-zero. This is independently reproducible before any C01 correction:

```text
CURRENT_STATE.json phase: IP-03-08_READY_FOR_CONTINUOUS_IMPLEMENTATION
Verifier result before correction: REFACTOR_AUTHORITY_OK 2026-08-21.2 67a4d98e90950a78a04e4ab2b5a6b6a164408567dee83f6d211b2b4e54a2c164
Required C01 phase after reconciliation: IP-03-08_READY_FOR_FINAL_REVIEW
Verifier assertion under required final phase: state.phase !== IP-03-08_READY_FOR_CONTINUOUS_IMPLEMENTATION
```

## Scope and disposition

`verify-current-state.mjs` is outside C01 Allowed Scope. The package also
protects validation scripts and forbids expanding the correction package.
Changing the verifier would be an unauthorized scope expansion; leaving the
phase unchanged would fail the reported handoff defect. No production,
test, fixture, lockfile, configuration, evidence history, or user data was
changed to work around this conflict.

## Required owner/package action

Sol/owner must reconcile the authority package before a truthful C01 handoff
can be completed: either authorize the minimal verifier update to accept the
final-review phase, or issue a corrected C01 package whose acceptance command
and Allowed Scope are internally consistent. Until then, the Continuous
Completion Report cannot truthfully end with `READY FOR SOL FINAL REVIEW: YES`.
