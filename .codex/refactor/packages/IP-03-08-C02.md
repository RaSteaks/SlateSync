## Required Changes

### 1. Correct task restore, switch, autosave and task actions

1. Restore every persisted task projection atomically and clear every absent
   projection before committing the selected task. A task must never inherit
   another task's table, edits, metadata, recognition, input or settings.
2. Prime/clear the retained CSV Worker in the same task-switch lifecycle so a
   restored Resolve table exports exact bytes after relaunch.
3. Restore persisted metadata/warnings/directory, slate CSV, provider, model,
   prompt, accuracy, scenario, records and save state as applicable without
   changing the version-1 task format.
4. Implement project-scoped new/load/switch/delete and visible save
   status/retry. Preserve one serialized in-flight save and the latest
   immutable pending snapshot.
5. Prevent a late save for task/project A from changing the active projection
   after selection has moved to task/project B. Flush or otherwise safely
   resolve pending saves before navigation without introducing a second writer.

### 2. Restore slate CSV and Worker-owned CSV semantics

1. Implement slate CSV load/replace/clear, provider-free direct merge and
   recognition-result merge through the typed CSV Worker.
2. Preserve exact bytes, original table shape/order, sparse edits, metadata
   backfill, matching/conflict/missing behavior, Comments allowlist, widths,
   standalone export, filenames and cancel results.
3. Remove Renderer `tableKeys()` business semantics. Obtain canonical expected
   material keys through an existing single-source module behind an authorized
   Worker/Main boundary without changing Shared Contract v1.
4. Test Worker task errors, infrastructure recovery, late replies, restored
   retained state, overlapping export/dialog guards and termination.

### 3. Restore image/PDF preparation parity

1. Reuse or adapt the retained single-source preparation algorithms so modern
   image/PDF input preserves fast/precise profiles, full/header/detail/core
   views, crop/overlap/page order, compression dimensions/quality, filenames
   and page counts.
2. Preserve direct-PDF eligibility, OCR restrictions, request-size safety,
   page limit, password/invalid PDF and recoverable error semantics.
3. Keep heavy work in the typed preparation/pdf.js Worker; bound/yield work and
   release page/document/Worker/object-URL resources on replace, supersession
   and unmount.
4. Add differential fixtures comparing modern prepared requests with the
   retained compatibility path. Do not change expected behavior to match the
   reduced modern implementation.
