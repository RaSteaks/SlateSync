# IP-02: Shared Contract v1 and Typed Preload

Prerequisite: Within approved Batch 01-02, IP-01 has reached a passing local checkpoint. No Sol review or model switch occurs between IP-01 and IP-02.

## Objective

Replace the Renderer-visible `window.electronAPI` surface with the domain-grouped, typed `window.slateSync` gateway and unified `Result<T>`/`AppError` model while preserving every current operation and legacy UI behavior through one bounded adapter.

## Allowed Scope

- `src/shared/contracts/**`, `src/shared/errors/**`, `src/shared/domain/**`
- `src/preload/**`, `src/main/ipc/**`
- `electron/preload.cjs`, `electron/ipc-handlers.mjs`
- `public/electron-bridge.js` as the single temporary legacy adapter
- `package.json` scripts only if required to validate generated contracts; no new dependency
- `test/electron-bridge.test.mjs`, `test/electron-ipc.test.mjs` only to strengthen/update contract expectations
- New tests under `test/refactor/ip-02/**`
- `.codex/refactor/adr/**`, `.codex/refactor/evidence/IP-02/**`
- `.codex/refactor/COMPATIBILITY_CONTRACT.md` only to append the approved transitional mapping; never rewrite Gate 00 facts
- `.codex/refactor/DECISION_QUEUE.md` only after a Stop Condition

## Protected Scope

- Main business services, recognition algorithms, providers, OCR, SQLite, Project Library, task persistence, dialogs, scanner, CSV Worker/algorithms, and all UI except the bridge adapter
- Current IPC channel transport names unless the package records an exact internal mapping and maintains legacy behavior
- All data formats, environment semantics, error text/status at the legacy adapter boundary, and native dialog behavior
- Design System/features and all IP-00 goldens

## Required Changes

1. Define exact DTOs and domain APIs for `window.slateSync.app`, `.projects`, `.tasks`, `.recognition`, `.files`, and `.settings`. Project-owned scenario operations belong to `.projects`; provider-key and OCR configuration belong to `.settings`.
2. Every request method returns `Promise<Result<T>>`, where failures use `{ code, message, retryable }`. Preserve meaningful existing codes/statuses and map unknown failures deterministically without leaking stack traces, filesystem paths, API keys, or raw Electron error objects.
3. Recognition progress subscription returns an idempotent unsubscribe function. Registering/subscribing/unmounting must never leave a listener that updates stale state. Do not add a public recognition-cancel operation because none exists in the compatibility baseline.
4. Expose only `window.slateSync` from the production Preload. Do not expose `ipcRenderer`, generic invoke/send helpers, raw channels, filesystem, SQLite, or secrets.
5. Keep the existing Main handlers or refactor them into narrow domain handlers without changing their service calls, validation, write leases, timing, persistence, or return data. Raw IPC names remain confined to Main/Preload.
6. Adapt `public/electron-bridge.js` to call `window.slateSync` and translate `Result<T>` back into the exact raw-success/throwing behavior expected by `public/app.js`. This file is the only authorized compatibility layer and must be marked for IP-08 removal.
7. Preserve `ArrayBuffer`/typed-array save semantics without converting binary data into number arrays. Preserve all native dialog operations and Project Library transfer serialization.
8. Add compile-time contract tests, runtime Preload exposure tests, Main/Preload mapping tests, failure-redaction tests, listener cleanup tests, and legacy adapter parity tests. Freeze Shared Contract v1 in an ADR after Joint Gate 01-02.

## Existing Behavior That Must Remain

- All 27 current request operations and recognition progress behavior remain available to the legacy UI.
- Recognition request/result/progress, timeout/retry, `AbortError`, page order, provider routing, write leases, task persistence timing, dialogs, and CSV byte save remain unchanged.
- Legacy users see the same success values and thrown message/status semantics through `public/electron-bridge.js`.
- Security remains `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`.

## Public Interfaces

- New frozen Renderer API: `window.slateSync` domain namespaces and Shared Contract v1.
- `Result<T>` and `AppError` match Architecture Invariants exactly.
- Event subscription returns `() => void`.
- `window.electronAPI` is removed from Preload; compatibility exists only in the imported legacy bridge functions, not as a second global.
- No generic public IPC function and no cancel-recognition method.

## Acceptance Tests

- Typecheck proves Main/Preload/Renderer consume one Shared Contract without `any` or duplicated DTO declarations.
- Runtime inspection proves the only bridge global is `slateSync`, with the exact approved namespace/method set and no channel strings in Renderer bundles.
- Each legacy operation has a mapping test for argument and success shape; representative failures prove code/message/retryable mapping and legacy throw parity.
- Recognition listener tests cover multiple subscriptions, unsubscribe twice, invocation success/failure, destroyed sender, and React unmount simulation.
- Binary tests prove exact `ArrayBuffer` byte range across typed Preload and native save.
- `npm run check`, typecheck, `npm test`, modern tests, Electron legacy/modern smoke, and directory build all pass.
- Gate 00 recognition/CSV/persistence/contracts/visual goldens remain green.

## Performance Constraints

- Gateway wrapping adds no measurable binary copy and less than 1 ms median overhead per local invocation in a 1,000-call synthetic test.
- Progress delivery does not rerender or allocate through a global store in this package.
- No additional long-lived listener remains after unsubscribe; listener count returns to baseline.

## Stop Conditions

- Any current operation lacks a safe domain placement or exact DTO can only be guessed.
- A second global bridge, generic invoke API, public raw channel, secret, filesystem, or SQLite handle would be exposed.
- Error unification changes legacy-visible message/status/retry semantics or hides a real regression.
- A data shape, channel behavior, dialog, ownership boundary, or cancellation contract must change.
- More than the one named legacy adapter is required.

## Deliverables

- Shared Contract v1 source and declarations
- Typed sandbox-compatible Preload and domain mapping
- Single bounded legacy bridge adapter with removal marker
- Contract/error/listener/binary parity tests
- Shared Contract ADR, evidence, comments, and Completion Report
