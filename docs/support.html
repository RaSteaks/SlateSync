核心功能Core features

场记单识别Slate recognition

支持 PDF、JPEG、PNG、WebP。PDF 在本机逐页栅格化，结合本地 OCR 与视觉模型抽取场、镜、次与条次状态。 Works with PDF, JPEG, PNG and WebP. PDFs are rasterized page by page on your Mac; local OCR plus a vision model extract scene, shot, take and take status.

结构校对Structural review

条号对账、场镜次序检查与完整性告警；识别结果在导出前必须经过人工确认。 Take-number reconciliation, scene/shot order checks and completeness warnings. Results always require human confirmation before export.

Resolve CSV 回填Resolve CSV backfill

只更新匹配到的素材与允许写入的字段，保留原 CSV 的编码、分隔符、换行和其余内容。 Only matched clips and permitted fields are updated. The original CSV's encoding, delimiter, line endings and untouched content are preserved.

slate.txt 元数据slate.txt metadata

可选扫描素材目录中的 slate.txt，自动补充 Camera FPS 与 Shoot Day。 Optionally scan a clip folder's slate.txt to fill in Camera FPS and Shoot Day automatically.

项目库与加密Project Library & encryption

项目、任务、诊断与场记结构 Profile 保存在本地 SQLite 项目库，并以 AES-256-GCM 加密存储，密钥保存在本机钥匙串。 Projects, tasks, diagnostics and slate-layout profiles live in a local SQLite library, encrypted with AES-256-GCM; the key stays in your Mac's keychain.

项目包导入导出Project packages

以独立项目包或整个项目库迁移数据；单项目导入创建新项目 ID，整库导入则切换到导入的项目库。 Move data as a single project package or a whole library. Importing a project creates a new project ID; importing a library switches to the imported library.

模型服务Model services

内置 OpenAI、OpenRouter、阿里云、DeepSeek 等服务商预设，也可以添加多个 OpenAI 兼容连接和手动模型 ID。 Includes presets for providers such as OpenAI, OpenRouter, Alibaba Cloud and DeepSeek. You can also add multiple OpenAI-compatible connections and manual model IDs.

本机 MCP（可选）Local MCP (optional)

让 Codex、Claude Code 等 AI 客户端在你授权的目录内调用识别、预览与导出工具，默认关闭。 Lets AI clients such as Codex and Claude Code call recognition, preview and export tools inside directories you grant. Off by default.

快速上手Getting started

  1. 创建项目Create a project

    在项目库中新建项目；项目设置只影响当前项目。 Create one in the Project Library. Project settings apply only to that project.

  2. 配置 ProviderConfigure a provider

    在全局设置中选择内置预设或自定义 OpenAI 兼容接口，填写 API Key 和必要的 Base URL，API Key 存入本地 AES-256-GCM 加密文件。保存后先验证连接，再单独验证模型的视觉能力。 In Global Settings, pick a preset or a custom OpenAI-compatible endpoint, then enter the API key and, when needed, the base URL. The key is stored in a local AES-256-GCM encrypted file. After saving, validate the connection, then separately verify the model's vision capability.

  3. 导入场记单Import a slate

    支持 PDF、JPEG、PNG、WebP；任务会保存场记单、媒体、元数据和识别结果。 PDF, JPEG, PNG and WebP are supported. The task keeps the slate, media, metadata and recognition results together.

  4. 识别与校对Recognize & review

    本机完成 OCR 后，由视觉模型做结构化理解。识别可取消；完成后逐条检查场、镜、次与条次状态。 OCR runs locally, then the vision model does the structured understanding. Recognition can be cancelled; afterwards review every scene, shot, take and status.

  5. 载入 Resolve CSVLoad the Resolve CSV

    导入 CSV 进行条号对账与场镜次序检查，可选扫描素材目录中的 slate.txt 补充元数据。 Import the CSV for take reconciliation and order checks, and optionally scan a clip folder's slate.txt for metadata.

  6. 预览回填并导出Preview & export

    在回填预览中人工校对每一条，确认后导出；导出保留原分隔符、换行与 BOM 语义。 Proof each entry in the backfill preview, then export. Delimiters, line endings and BOM semantics are preserved.

支持的识别方式Recognition methods

三种方式可组合使用；OCR 引擎不可用时可按设置降级，或设为必需时停止识别。 The three methods can be combined. If an OCR engine is unavailable you can fall back per settings — or require it and stop recognition instead.

Resolve 字段回填Resolve field mapping

只有下列字段会被写入，且仅在成功匹配后更新。 Only these fields are written, and only after a successful match.

Resolve 字段field 数据来源Source
Scene 场记单中的场次Scene from the slate
Shot 场记单中的镜Shot from the slate
Take 场记单中的次Take from the slate
Comments 按设置写入过条、保条标记；其他情况为空Circled / printed-take marks per settings; otherwise empty
Camera FPS 素材目录 slate.txt 的 Sensor FPSSensor FPS from the clip folder's slate.txt
Shoot Day 素材目录 slate.txt 的 Shot DateShot Date from the clip folder's slate.txt
字段无法确认时不会被强行写入，必须人工校对；合并导出不会掩盖未匹配到完整素材记录的情况。 Fields that cannot be confirmed are never force-written and require manual review. Merge exports never paper over clips lacking a complete matching record.

项目与数据Projects & data

存储位置Where data lives

设置与日志位于 ~/Library/Application Support/SlateSync/；默认项目库位于 ~/Library/Application Support/Local SlateSync Library/，也可以在应用中选择其他位置。 Settings and logs live in ~/Library/Application Support/SlateSync/; the default Project Library in ~/Library/Application Support/Local SlateSync Library/. You can pick another library location in the app.

本地加密Local encryption

正常启动会自动把项目库索引、项目设置、任务、诊断、场记 Profile 与 JSON 快照转换为 AES-256-GCM 加密存储；密钥保存在本机登录钥匙串。原始媒体与缓存、机器级配置和日志不在加密范围内。 At launch the library index, project settings, tasks, diagnostics, slate profiles and JSON snapshots are migrated to AES-256-GCM encrypted storage; the key stays in the login keychain. Raw media and caches, machine-level configuration and logs are outside that scope.

迁移与备份Migration & backup

优先使用应用内导出：单个项目包或整个项目库。单项目导入创建新项目 ID；整库导入切换到导入的项目库。任务、诊断、Profile 与设置会随项目保留。跨设备请勿直接复制内部加密目录——那需要原机器钥匙串密钥。 Prefer in-app export: a single project package or the whole library. A project import creates a new project ID; a library import switches to the imported library. Tasks, diagnostics, profiles and settings are carried along. Don't copy the internal encrypted folder across Macs — it needs the original machine's keychain key.

日志Logs

运行日志按天保留 7 天，记录脱敏事件；不记录凭据、原始请求、媒体路径或模型响应正文。 Run logs are kept locally for 7 days by day and record redacted events only — never credentials, raw requests, media paths or model response bodies.

本机 MCPLocal MCP

可选的本机服务，让 Codex、Claude Code 等 AI 客户端调用 SlateSync 的识别、元数据扫描、回填预览和 CSV 导出工具。它不启动应用界面，也不修改桌面项目库。 An optional local service that lets AI clients such as Codex and Claude Code call SlateSync's recognition, metadata scanning, backfill preview and CSV export tools. It does not open the app window or change your Project Library.

  • 启动：在设置 → MCP 中点击“一键启动 MCP”，应用会查找源码目录、增量构建并启动服务。首次构建需要 Xcode / Swift 工具链和网络。 Start: in Settings → MCP, click Start MCP. The app finds the source checkout, runs an incremental build and starts the service. The first build needs the Xcode / Swift toolchain and network access.
  • 连接：点击“添加到 Codex”或“添加到 Claude Code”，通过已安装的官方 CLI 写入用户级配置；也可以复制托管配置。 Connect: click Add to Codex or Add to Claude Code to write a user-level entry with the installed official CLI, or copy the managed configuration.
  • 授权：不添加授权目录也能启动和连接，但所有文件读取和导出都会被拒绝。真实模型请求需要单独允许，可能产生服务商费用。 Grant: the service starts and connects without directory grants, but every file read and export is denied. Real model requests need separate permission and may incur provider charges.
  • 停止：可以开启“随 SlateSync 自动启动 / 停止”。退出应用会停止服务及全部托管连接，关闭设置窗口不受影响。 Stop: you can turn on automatic start and stop with SlateSync. Quitting the app stops the service and all managed connections; closing Settings does not.
工具返回的结果会交给你连接的 AI 客户端，该客户端可能把它们发送给自己的服务。详见隐私政策第 8 条。 Tool results go to the AI client you connect, which may send them to its own service. See §8 of the privacy policy.

常见问题FAQ

SlateSync 需要注册账号吗？Do I need an account?
不需要。应用在本机运行，没有账号体系；联网识别使用你在全局设置中自行配置的模型服务。 No. The app runs on your Mac with no account system. Online recognition uses whichever model service you configure in Global Settings.
我的 API Key 保存在哪里？安全吗？Where is my API key stored?
API Key 以 AES-256-GCM 加密文件保存在本机，主密钥为独立文件，权限均限制为当前用户。两文件同时泄露仍可被解密。API Key 不进入项目包、项目库导出或 Git，也不回填到界面；旧钥匙串凭据需重新填写。 Keys are stored in a local AES-256-GCM encrypted file with a separate master-key file, both restricted to the current user. Possession of both files allows decryption. Keys are excluded from project packages, library exports and Git, and never echoed back into settings. Old Keychain credentials must be entered again.
识别时哪些内容会被发送出去？What gets sent during recognition?
本地准备页面图片（必要时含局部放大图）与 OCR 证据后，识别请求还会携带源文件名及可选的项目提示、场记 CSV 记录和版式提示；配置的 API Key 用于请求头认证。原始 PDF 不会上传。没有配置 Provider 时，识别不会产生模型网络请求。详见隐私政策。 After local preparation, recognition sends page images, with close-ups when needed, and OCR evidence together with the source filename and optional project prompts, slate CSV records and layout hints. A configured API key is used in the authentication header. The original PDF is not uploaded. With no provider configured, recognition makes no model network request. See our privacy policy.
验证模型会产生费用吗？Does verifying a model cost money?
可能会。保存配置不发起模型调用，验证连接只刷新模型列表；验证视觉能力会用内置测试图片发起一次模型调用，可能产生费用。测试图片不包含你的场记单或项目内容。 It can. Saving makes no model call and validating the connection only refreshes the model list. Verifying vision capability makes one model call with a built-in test image, which may incur a charge. That image contains none of your slates or project content.
PaddleOCR 为什么需要单独安装？Why does PaddleOCR need a separate install?
应用只内置 runner 与固定依赖清单，不携带 Python、虚拟环境或模型。安装需要 Python 3.10 或更高版本的环境与网络，在应用内选择环境后进行；如果你只用 macOS Vision OCR，可以完全跳过这一步。 The app bundles only the runner and a pinned dependency list — no Python, virtualenv or models. Installing requires a Python 3.10+ environment and network access, done in-app after you pick the environment. If you only use macOS Vision OCR you can skip it entirely.
为什么有的字段导出后是空的？Why are some fields empty after export?
无法确认的识别字段不会被强行写入，必须人工校对。请在回填预览中查看条号缺失、场镜次序与完整性告警，手动补全后再导出。 Fields that cannot be confirmed are never force-written — they need human review. Check the backfill preview for missing takes, order issues and completeness warnings, fix them manually, then export.
更换电脑时如何迁移项目？How do I move projects to a new Mac?
在旧电脑使用应用内导出（单个项目包或整个项目库），在新电脑导入。单项目导入会创建新的项目 ID；整库导入会切换到导入的项目库。不要直接复制内部加密目录：它绑定原机器钥匙串，丢失密钥无法解密。 Export in-app on the old Mac (a project package or the whole library) and import on the new one. A project import creates a new project ID; a library import switches to the imported library. Don't copy the internal encrypted folder directly: it is bound to the original machine's keychain, and without that key the data cannot be decrypted.
导出会改动我的原始 CSV 文件吗？Will export modify my original CSV?
不会。导出保留原 CSV 的编码、分隔符、换行与 BOM 语义以及未匹配字段，只更新匹配到的字段；源文件保持不变，请以导出的新文件为准。 No. Export preserves the original encoding, delimiter, line endings, BOM semantics and unmatched content, updating only matched fields. Your source file is untouched — use the exported file.
如何归档或删除项目？How do I archive or delete a project?
归档会把项目移出活跃列表，恢复后仍保留项目数据。永久删除是独立操作，需要逐字输入项目名称确认，且无法恢复。 Archiving removes a project from the active list and restoring keeps its data. Permanent deletion is a separate action that requires typing the exact project name and cannot be undone.
识别失败或结果异常怎么办？Recognition failed or looks wrong — what now?
先在全局设置中检查 Provider 的 Base URL、API Key 与模型是否有效，以及 OCR 配置是否可用；失败时应用会按设置降级为页面图片识别，或在设为必需时停止并报告错误。失败详情可查看帮助中的日志（本地保留 7 天、内容脱敏）。修正配置后可直接重试，当前编辑会先被保留。 First check the provider's base URL, API key and model in Global Settings, and that your OCR configuration is available. On failure the app falls back to image-only recognition per settings — or stops and reports if OCR is set to required. Details are in the Help logs (kept locally 7 days, redacted). Your current edits are preserved, so you can retry after fixing the configuration.
钥匙串密钥丢失了怎么办？What if the keychain key is lost?
加密密钥保存在本机登录钥匙串。若钥匙串数据丢失且没有应用内导出的备份，已加密数据无法恢复。请在升级、迁移或重装系统前，先通过应用内导出保存项目包或项目库备份。 The encryption key lives in the local login keychain. If that data is lost and you have no in-app export, encrypted data cannot be recovered. Before upgrading, migrating or reinstalling macOS, export a project package or library backup from within the app.

已知边界Known limitations

  • 仅支持 macOS 15.0 及以上版本，不提供 Windows 或 Linux 版本。 macOS 15.0 or later only; there is no Windows or Linux version.
  • 项目库与项目包当前为 v1 格式，升级、迁移或回退前请保留独立备份。 The Project Library and packages use the v1 format; keep a separate backup before upgrading, migrating or rolling back.
  • 本机 MCP 目前需要本机源码目录，尚未包含在安装包中；Mac App Store 沙盒版本不会启动它。 Local MCP currently needs a local source checkout and is not included in the installer. The Mac App Store sandbox build does not start it.
