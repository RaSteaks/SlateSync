# SlateSync UI 优化与验证

> 历史资料归档（2026-09-16）：以下描述原 UI 工作期间的实现和验证记录，
> 不代表当前分支已经实现或重新通过这些检查。所引用的临时日志、结果包及
> `ui-refresh/` 证据未随本文入库；本次仅核对资料内容，未复跑历史 UI 验收。


日期：2026-09-11。环境：macOS 15.7.3，Apple Silicon，原生 Debug 应用。
本轮仅修改应用/UI、原生表格外观桥接、测试及设计记录，未修改 Domain、Workflow、
持久化协议或 CSV 导出格式。所有运行使用独立临时项目库和测试凭据后端。

## 实现

- 工作台：任务标题、三个入口、主要识别操作；大素材预览、300 pt 配置面板、可展开高级设置。
- 900 pt 是工作区详情宽度的切换点；窄布局使用覆盖面板，任务栏独立显隐。
  原稿对照和配置开关先经过原生编辑提交与已有自动保存屏障。
- 表格密度为舒适 30 pt / 紧凑 24 pt；只更新行高，保留表格身份、选择和滚动位置，
  有活动编辑时延迟应用。原稿页码属于预览，不映射或选择结果行。
- 元数据扫描归入 Resolve CSV；窄窗口通过菜单保留合并、独立导出与回填导出的区别。
- 统一主题、状态栏、空状态、标题和可清除搜索；保留原生侧边栏、高亮和控件。
- 设置保留五个分类，使用原生分段控件与滚动表单；默认 780×620、最小 700×540。
  主窗口默认值仍为 1440×900，最小外框 960×600。

窗口探针测量标题栏而不硬编码其高度。实机诊断发现 macOS 15 设置窗口具有正确的
最小/最大尺寸，却缺少 `NSWindow.StyleMask.resizable`；仅补上此原生标志，
不写窗口 frame、不替换窗口、不接管恢复。表格数据和业务状态仍归原有模型所有。

### 最终复核记录

最终全量回归 322 项，1 跳过、0 失败。日志：`ui-refresh/swift-test.log`。
跳过项为需要独立离线模型根目录的 Paddle 实际预热；前台表格回归已显式启用并通过。

在完整 11 项 UI 套件之后，又通过双页 PDF 和更新后的外观矩阵 2 项补充回归，
合计覆盖 12 个不同 UI 测试用例。双页 PDF 测试在第 2 页进入结果对照后翻回第 1 页，
断言结果仍为同一行且选择保持。最终截图使用补充回归结果：
`ui-refresh/ui-final-evidence-summary.json`，原始结果包位于
`/tmp/slatesync-ui-final-evidence2.xcresult`。完整套件结果包位于
`/tmp/slatesync-ui-final-suite.xcresult`。

万行表格 1 次预热、5 次测量：加载最长 68.81 ms（门槛 1200 ms），
末行编辑最长 2.70 ms（门槛 100 ms），可见原生文本单元格均为 140 个（上限 300），
释放后测得额外 footprint 为 0。前台滚动的既有 DisplayLink 计数指标为
143.50 samples/s（门槛 45），这是回调计数口径，不能等同于逐帧 GPU 呈现率。
原始指标：`ui-refresh/native-csv-scale.json`、`ui-refresh/native-csv-foreground.json`。

## 视觉与可访问性检查

- 40 张最终截图直接导出自通过的 UI 测试，未经裁切或修图。尺寸单位为 pt，PNG 保留 Retina 像素。
- 以长中文素材文件名、中文正文、真实原生表格进行检查。任务名称单行截断且有完整提示；
  原稿页码和面板关闭按钮在最小窗口仍可操作。
- 新增面板、搜索清除、预览操作的可访问性标识与辅助说明；原生按钮和表格保留键盘访问。
  搜索清除后焦点回到输入框；编辑器方向键不会被外层翻页快捷键接管。
- 主题色在对应不透明画布上的对比度：强调色 6.20/6.71、成功 4.90/9.58、
  警告 5.41/10.29、错误 5.33/8.30（浅/深），计算值保留在 `ui-refresh/contrast.json`。
  该计算不代替系统材料与原生次级文字的视觉检查。
- 没有新增自定义过渡动画、自动滚动或闪烁提示；布局变化不依赖动画。
  系统“减少动态效果”开关未为测试而修改。

## 证据边界

- 当前显示器工作区不能容纳指定位置上的完整 1440×900 外框，macOS 将宽窗口实际高度
  限制在约 883–885 pt；文件名记录真实尺寸。960×600 按原值验证通过。
  1440×900 的完整实机截图仍需更大的可用显示区域，不能把当前宽图当作该尺寸验收。
- 修改前已有隔离库的浅/深色基线截图：`/tmp/slatesync-ui-evidence/before/manifest.json`，
  来源 `/tmp/slatesync-ui-before-retry.xcresult`。该基线只覆盖当时项目库/设置画面，
  并非所有页面的完整改前矩阵；原始全屏图包含桌面背景，未复制进代码库。
- OCR 取消、失败、保存失败及组合输入通过注入故障和原生编辑测试验证；未调用真实付费
  Provider。离线 Paddle 实际模型预热需要独立的运行时与模型根目录，本轮不伪造其通过结果。
- 测试过程中遇到系统警告窗口及 Xcode 失败符号化停滞；未更改系统权限或显示设置。
  失败案例修复后重新运行，以上通过结果来自明确完成的测试结果包。

## 复跑

```sh
swift build -Xswiftc -warnings-as-errors
swift test
xcodebuild -project SlateSync.xcodeproj -scheme SlateSync \
  -destination 'platform=macOS' -derivedDataPath DerivedData/UIRefresh \
  -only-testing:SlateSyncUITests test
```

需要前台性能证据时，单独运行已有原生表格测试并设置
`SLATESYNC_SM08_FOREGROUND_GATE=1`、`SLATESYNC_SM08_METRICS_DIR` 指向临时输出目录。
它会打开测试窗口，不应与 Xcode UI 自动化同时运行。
