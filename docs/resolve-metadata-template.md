# Resolve 内置元数据模板

## 范围与官方依据

模板 ID：`resolve-21.1-csv-v1`。在「项目设置 → 导出配置 → 导出模板」选择。
没有后期提供的样表时，也能从场记记录生成表格、补齐素材信息并导出 CSV。
已有项目的自定义配置不自动迁移。模板是 SlateSync 根据文档实现的适配器，
不是 Blackmagic Design 随附或认证的模板。

本次依据用户提供的官方文件，未把 PDF 内的操作步骤当作执行授权：

- `DaVinci_Resolve_21.1_Reference_Manual.pdf`：第 18 章，406–412 页定义原生
  元数据、文本备注、自定义字段及只读属性；421–423 页定义 CSV/ALE 导入导出、
  素材匹配和三种合并策略。该文件 PDF 页码与印刷页码一致。
- `DaVinci-Resolve-18-Editors-Guide.pdf`：印刷 254 页列出常用元数据；
  257–260 页（PDF 273–276 页）示范 CSV 导入、关闭不存在的时码匹配、覆盖
  文件包含的字段并保留其他字段，以及检查导入结果。
- [Resolve 18 官方编辑指南](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-18-Editors-Guide.pdf)
  可作为可公开获取的同源参考。21.1 以用户提供的原始文件为依据。

手册不是完整的 CSV/ALE 线格式字典：没有穷举所有 CSV 表头、布尔值表示、
自定义字段类型推断和 ALE 字段约束。下面区分文档语义与适配器实现选择；
合成字节测试不能替代目标版本的实际导入验证。

## 内置字段

| CSV 列 | 默认 | 数据含义与来源 | 官方依据 |
|---|---|---|---|
| File Name | 始终包含 | 原始素材文件名，含原有扩展名；素材清单或人工填写 | 21.1 p.422 文件名匹配 |
| Start TC | 始终包含 | 素材起始时码，原样保留；不使用时间线入点 | 21.1 pp.406,422 起止时码 |
| End TC | 始终包含 | 素材结束时码，原样保留；不以时长推算 | 21.1 pp.406,422 起止时码 |
| Reel Name | 始终包含 | 素材实际卷名；不自动用场记卡号替代 | 21.1 p.422 Reel Name 匹配 |
| Clip Directory | 始终包含 | 素材所在源目录，与 File Name 共同定位源文件 | 21.1 pp.422–423 源路径匹配 |
| Scene | 开启 | 场次；场记有效文本回填，否则保留清单原值 | 21.1 p.412 |
| Shot | 开启 | 镜号，允许字母；不套用旧数字补位规则 | 21.1 p.412 |
| Take | 开启 | 条次；保留已有前导零 | 21.1 p.412 |
| Comments | 开启 | 文字备注；不转换为 `_OK`/`_KP` | 21.1 p.412 |
| Description | 可选 | 内容描述；场记有效文本回填 | 21.1 p.406；18 p.254 |
| Keywords | 可选 | 关键词；清单原值或人工填写，保留原有分隔表示 | 21.1 p.408；18 pp.254,259 |
| Camera # | 可选 | 机位；清单原值或人工填写 | 21.1 p.412 |
| Shoot Day | 可选 | 拍摄日；清单原值或人工填写 | 21.1 p.406 |
| Camera Type | 可选 | 摄影机类型；清单原值或人工填写 | 21.1 p.406 |
| Audio Notes | 可选 | 声音备注；清单原值或人工填写 | 21.1 p.406 |

`Clip Directory` 是现有 Resolve CSV 适配中的目录列名；手册确认的是“源文件路径
匹配”的能力，没有在相关章节给出此 CSV 表头的逐列规范。它不等于含文件名的
完整路径，不增加一个未经确认的 `Source File Path` 列冒充原生字段。上述表头与
Unicode 编码组合仍需要用目标 Resolve 版本导出的真实 CSV 做往返验收。

本版只开放这些文档可追溯的文本字段。Good Take、星级、Clip Color、Flags、
自定义数值/时码/复选框等虽然在手册中有定义，但文件表示尚未确认，不凭猜测
添加到内置模板。帧率、路径和文件名也不被当成可通过 CSV 修改媒体属性的指令。

## 导出行为

- 内置模板固定原生列名和逗号分隔符；可调整列顺序和六个可选字段，五项
  素材匹配列不能关闭。默认另外包含 Scene、Shot、Take、Comments。
- 源文件编码与输出编码分开记录。默认 UTF-8 + BOM / CRLF 是应用选择，
  不声称是官方唯一要求；保留现有 Unicode 编码和换行选项。
- 使用内置模板时只输出选中的字段；自定义 CSV 的原有保留列流程继续兼容。
- 导入素材清单时，五项身份信息来自清单原值。清单不能和“后期要求的样表”
  混为一谈：选择内置模板后，仍可自行从 Resolve 导出素材清单作为数据来源。
- 未载入清单时，预览生成可编辑的空身份单元格。绝不把场记单 PDF 文件名、
  卡号与视频码拼接的猜测结果、虚构扩展名或零时码充当素材身份。
- 缺失五项信息时显示逐列数量。最终保存要求 File Name 有值；其他列允许为空，
  因为官方允许按实际数据选择匹配条件。缺失字段不可在接收端用作匹配条件。
- 回填只使用已有素材身份规则匹配记录；不同描述/备注等造成冲突时保留清单
  原值。未匹配的素材行不丢失。新增普通元数据字段不触发相机机位推断。
- 手工更正优先于场记与原清单；导出不重写文本、前导零、分号时码或目录。
  任务快照保存编辑列头，保证重排与恢复时位置对应。预览和文件使用同一 Worker。

## Resolve 接收端设置

选择 `File > Import Metadata To > Media Pool` 或 `Selected Clips`，再选 CSV。
按交付数据勾选文件名、起止时码、Reel Name 或源路径匹配；不要因为输出包含
空列就勾选对应条件。Resolve 18 教程的无时码样例明确取消时码匹配。

三种合并策略（21.1 p.423）：

1. 只更新源文件有有效值的项目：会覆盖目标已有值，并非“仅补目标空值”。
2. 更新源文件列出的全部字段：空值也会覆盖，但保留未列出的字段。
3. 更新列出的字段并清空其他字段：会额外清除未交付字段，不能作为默认交接建议。

建议首轮采用第一项，在少量测试素材中检查，再扩大导入范围。SlateSync 不操控
接收端的合并选项，也不声称 CSV 能编码“追加”或“仅补目标空值”等指令。

## 验证与后续适配

自动化覆盖必含列、Main/Renderer 归一化一致性、选列、中文多行备注、字母镜号、
前导零、起止时码、Windows/macOS 目录、源数据不变、缺失文件名纠正、重复
表头拒绝，以及任务保存列序后的重排。浏览器使用合成网关和无头 Chromium。

仍需目标软件验收：从 Resolve 21.1 填写全部候选字段后导出原生样本，核对表头、
编码、关键词表示和源路径匹配，再导入 SlateSync 结果并从 Resolve 重新导出对比。
未经此步骤不宣称“完整 Resolve 字段支持”或“已通过 Resolve 导入认证”。

ALE 本轮不提供伪转换入口。21.1 pp.422–423 确认了 ALE 通道，但未给出足以实现
完整写入器的格式定义；后续需要官方格式资料和真实 ALE 样本建立独立适配器。

## 项目默认与导入的后期模板

未配置的项目默认选择内置 Resolve CSV。已有明确保存的自定义配置不被覆盖。
进入「项目设置 → 导出配置」点击「导入 CSV 模板」，选择后期样表，再点击
「保存项目设置」。该项目后续新任务默认使用保存的模板；旧任务明确保存的会话
覆盖仍保留。模板结构保存在项目中，后续不需要原 CSV 文件。

导入仅提取列名、顺序、分隔符、编码、BOM 和换行，不把样表中的素材行用于新任务。
支持最多 5 MB、256 列；空白、重复或含控制字符的列名会拒绝。支持只有表头的 CSV。
GBK/GB18030 样表会提示改用 UTF-8 输出。无有效列的模板不能导入。

导入模板使用样表本身的列集合，不自动补列。上面的五个素材匹配字段是**内置默认
模板**的固定列。官方英文表头对应已知字段，源素材中同名列原样带入；未知列保留
并可在预览中填写，单独从场记生成表格时没有对应数据的格子留空。导入模板不代表
所有自定义表头都获得 Resolve 原生字段身份；接收端仍按其样表与匹配设置验收。
