    隐私政策 Privacy Policy

    本政策说明 SlateSync for macOS 在本机保存什么、发送什么，以及不收集什么。 This policy explains what SlateSync for macOS stores on your Mac, what it sends, and what it does not collect.

    摘要Summary

    • SlateSync 没有账号系统，也不向开发者运营的服务器上传任何数据：没有统计、广告或崩溃上报。 SlateSync has no account system and uploads nothing to developer-operated servers: no analytics, ads or crash reporting.
      第 2 条§2
    • 项目数据保存在本机；项目库内容以 AES-256-GCM 加密，密钥保存在本机登录钥匙串。 Project data stays on your Mac. Library contents are encrypted with AES-256-GCM; the key lives in your Mac's login keychain.
      第 3 条§3
    • 你主动识别时，页面图片、OCR 证据及识别上下文会发送给你配置的模型服务；原始 PDF 文件不会上传。 When you run recognition, page images, OCR evidence and recognition context go to the model service you configured. The original PDF file is not uploaded.
      第 4 条§4
    • 可选的 PaddleOCR 完全在本机运行；Python 环境与模型由你在本机选择和下载。 Optional PaddleOCR runs entirely on your Mac; you choose and download the Python environment and models yourself.
      第 5 条§5
    • 可选的本机 MCP 默认关闭；启用后，你连接的 AI 客户端可以处理你授权目录中的文件并取得结果，模型请求还需单独允许。 Optional local MCP is off by default. Once enabled, the AI client you connect can process files in directories you grant and receive the results; model requests need separate permission.
      第 8 条§8

    2我们不收集的数据What we don't collect

    • 没有账号、注册或登录。 No account, registration or sign-in.
    • 没有统计、行为分析、广告 SDK 或崩溃上报；数据不会发送到开发者运营的任何服务器。 No analytics, telemetry, ad SDKs or crash reporting; nothing is sent to developer-operated servers.
    • 我们不接收、出售、出租或共享用户数据。 We do not receive, sell, rent or share user data.
    • 模型请求只指向你配置的服务（见第 4 条）；主动安装 PaddleOCR 时还会访问软件源与模型下载服务（见第 5 条）；首次构建本机 MCP 时还会下载依赖（见第 8 条）。 Model requests go only to the service you configure (see §4); an optional PaddleOCR installation also contacts package and model sources (see §5), and the first local MCP build downloads its dependencies (see §8).

    3本地存储与加密Local storage & encryption

    设置、日志与默认项目库位于：Settings, logs and the default Project Library live in:

    • ~/Library/Application Support/SlateSync/（机器设置与日志machine settings and logs）
    • ~/Library/Application Support/Local SlateSync Library/（默认项目库，可在应用中更改位置default Project Library; the location can be changed in the app）

    正常启动时，项目库索引、项目设置、任务、诊断证据、场记结构 Profile 与 JSON 快照会自动转换为 AES-256-GCM 加密存储。加密密钥保存在本机 macOS 登录钥匙串，不会同步到 iCloud。 At launch, the library index, project settings, tasks, diagnostic evidence, slate-layout profiles and JSON snapshots are automatically stored encrypted with AES-256-GCM. The key is kept in the local macOS login keychain and never syncs to iCloud.

    以下内容不在该加密范围内：原始媒体与媒体缓存、机器级配置和运行日志。该边界保护本地文件内容，不隐藏目录名称，也不能替代整盘加密（如 FileVault）。 Outside this encryption boundary: raw media and media caches, machine-level configuration and run logs. This boundary protects file contents; it does not hide directory names and is not a substitute for full-disk encryption such as FileVault.

    若登录钥匙串中的密钥丢失且没有应用内导出的备份，已加密数据无法解密。迁移到新 Mac 请使用应用内导出，不要直接复制内部加密目录。 If the keychain key is lost without an in-app export, encrypted data cannot be decrypted. To move to a new Mac, use in-app export — do not copy the internal encrypted folder directly.

    项目可以归档并恢复；永久删除需要逐字输入项目名称。诊断证据按项目保留最近 20 次会话。 Projects can be archived and restored; permanent deletion requires typing the exact project name. Diagnostic evidence is kept for the latest 20 sessions per project.

    4你配置的第三方 AI 服务Third-party AI services you configure

    识别由你自行选择并配置的 OpenAI 兼容视觉服务完成（包括 Base URL、模型与请求并发等，均可在全局设置中修改）。应用内置 OpenAI、OpenRouter、阿里云、DeepSeek 等服务商的地址预设，预设本身不会发起连接。发起识别时，应用会向该地址发送： Recognition is performed by an OpenAI-compatible vision service that you choose and configure (base URL, model, concurrency and more, all editable in Global Settings). The app includes address presets for providers such as OpenAI, OpenRouter, Alibaba Cloud and DeepSeek; a preset alone makes no connection. When you start a recognition, the app sends to that address:

    • 本地栅格化得到的场记单页面图片，必要时包括同一页的局部放大图； Slate page images rasterized locally, with close-ups of the same page when needed;
    • 本地 OCR 证据：识别出的文字、置信度与坐标。 Local OCR evidence: recognized text, confidence and coordinates.
    • 识别上下文：源文件名、你填写的项目自定义提示，以及启用时的场记 CSV 记录（素材、场、镜、次与状态）、版式提示和输出字段设置。 Recognition context: the source filename, your project custom prompt, and, when used, slate CSV records (material, scene, shot, take and status), layout hints and output-field settings.
    • 如已配置 API Key，认证请求头会将该 Key 发送给所选服务。 If an API key is configured, an authentication header sends it to the selected service.

    原始 PDF 文件、完整项目库与其他项目内容不会随识别请求发送；API Key 只用于请求头认证。模型发现（列出可用模型）也只与你配置的服务通信。内容发送后，由该服务商按其隐私政策与条款处理。 The original PDF file, complete Project Library and other projects' content are not sent with recognition requests. The API key is used only in the authentication header. Model discovery also talks only to your configured service. Once sent, content is handled under the provider's own privacy policy and terms.

    验证连接只刷新模型列表；验证视觉能力时，应用发送的是内置测试图片，不包含你的场记单或项目内容，但可能产生一次模型调用费用。 Connection checks only refresh the model list. Vision capability checks send a built-in test image containing none of your slates or project content, and may incur the cost of one model call.

    使用 OpenRouter 时，请求头还包含应用名称和来源地址，默认值分别为 SlateSync 和本项目的 GitHub 地址，用于向该服务标识来源，可在设置中修改。 With OpenRouter, request headers also carry an app name and source URL, by default SlateSync and this project's GitHub address, to identify the source to that service. You can change them in Settings.

    不配置 Provider 时，应用不会为识别产生任何网络请求。设置中的服务商官网、密钥和文档链接，以及 GitHub 项目主页，只有在你点击后才由系统浏览器打开。 With no provider configured, recognition generates no network requests at all. Provider website, API key and documentation links in Settings, and the GitHub project link, open in your system browser only when you click them.

    5本地 OCROn-device OCR

    macOS Vision OCR — 使用系统提供的 Vision 能力，完全在本机运行，数据不离开设备。 Uses the system Vision framework, runs entirely on your Mac, and no data leaves the device.

    PaddleOCR（可选optional）— 推理同样完全在本机运行。应用不携带 Python、虚拟环境或模型文件；安装时需要你提供 Python 3.10+ 环境并联网下载依赖与模型（paddlepaddle / paddleocr 固定版本）。下载由你主动发起，直接连接相应软件源。 Inference likewise runs entirely on your Mac. The app bundles no Python, virtualenv or models; installing requires a Python 3.10+ environment you provide and a network download of pinned paddlepaddle / paddleocr dependencies and models. You start that download yourself, and it connects directly to the package sources.

    6运行日志Run logs

    运行日志只保存在本机 ~/Library/Application Support/SlateSync/ 下，按天保留 7 天后清理。日志记录脱敏事件，不包含凭据、原始请求、媒体路径或模型响应正文，也不会被上传。 Run logs are stored only under ~/Library/Application Support/SlateSync/ on your Mac and pruned after 7 days, by day. They record redacted events and never contain credentials, raw requests, media paths or model response bodies, and they are never uploaded.

    本机 MCP 的诊断信息单独写入 logs/mcp-service.log、mcp-build.log 和 mcp-client.log，位于同一目录下。这些文件同样只保存在本机、不会被上传，但不适用上述 7 天清理和脱敏规则，可能包含本地路径；不再需要时可以手动删除。 Local MCP diagnostics are written separately to logs/mcp-service.log, mcp-build.log and mcp-client.log in the same directory. They also stay on your Mac and are never uploaded, but the 7-day pruning and redaction above do not apply and they may contain local paths. You can delete them manually when no longer needed.

    7API KeyAPI keys

    服务商 API Key 使用 AES-256-GCM 加密保存在本机，随机主密钥保存在独立文件，均仅当前用户可读写。同时取得两文件的人仍可解密；不提供钥匙串的应用访问隔离。UI 不读取已保存凭据。Key 不会写入项目包、项目库导出、日志或 Git 仓库，也不会回填显示在设置界面。 Provider API keys are stored locally with AES-256-GCM encryption and a separate random master-key file, both restricted to the current user. Anyone with both files can decrypt the keys; this does not provide Keychain application isolation. The UI never reads saved credentials. Keys are never written into project packages, library exports, logs or Git, and never echoed back into the settings UI.

    8本机 MCPLocal MCP

    本机 MCP 是可选功能，默认关闭，只有你在设置中启动后才会运行。它让你连接的 AI 客户端（例如 Codex 或 Claude Code）调用 SlateSync 的识别、元数据扫描、回填预览和 CSV 导出工具，但不会修改桌面项目库、任务、全局设置或 API Key。 Local MCP is optional and off by default; it runs only after you start it in Settings. It lets the AI client you connect, such as Codex or Claude Code, call SlateSync's recognition, metadata scanning, backfill preview and CSV export tools. It does not change your Project Library, tasks, global settings or API keys.

    • 本地通信：服务通过本机 stdio 和仅当前用户可访问的 Unix socket 通信，不监听网络端口。 Local transport: the service uses local stdio and a Unix socket restricted to the current user. It listens on no network port.
    • 目录授权：未添加授权目录时，所有文件读取和导出都会被拒绝；路径在解析符号链接后仍须位于授权目录内。 Directory grants: with no granted directories, every file read and export is denied. Paths must stay inside a grant after symlinks are resolved.
    • 交给客户端的内容：工具返回的识别记录、CSV 预览和元数据会交给你连接的 AI 客户端。该客户端可能把这些内容发送给它自己的服务，处理方式受其隐私政策与条款约束。 What the client receives: recognition records, CSV previews and metadata returned by the tools go to the AI client you connect. That client may send them to its own service, under its own privacy policy and terms.
    • 模型请求：默认不允许，须单独开启。开启后，工具发起的识别会按第 4 条向你配置的服务发送内容，可能产生服务商费用。服务使用本机保存的 API Key 认证，工具结果不包含凭据。 Model requests: disabled unless you turn them on separately. Once enabled, tool-initiated recognition sends content to your configured service as described in §4 and may incur provider charges. The service authenticates with the API key saved on your Mac, and tool results never include credentials.
    • 构建与连接：首次构建需要 Xcode / Swift 工具链，并联网下载 MCP SDK 及其依赖。只有在你点击“添加到 Codex”或“添加到 Claude Code”时，应用才会调用对应的官方 CLI 写入客户端配置。 Build and connect: the first build needs the Xcode / Swift toolchain and downloads the MCP SDK and its dependencies. The app writes client configuration only when you click Add to Codex or Add to Claude Code, using that client's official CLI.

    这项服务目前需要本机源码目录，尚未包含在安装包中；Mac App Store 沙盒版本不会启动它。 The service currently needs a local source checkout and is not included in the installer. The Mac App Store sandbox build does not start it.

    9导出与共享Exports & sharing

    导出由你发起，写入你选择的位置： You start every export and choose where it goes:

    • 导出的 Resolve CSV 保持通用格式，写入你指定的位置； Exported Resolve CSVs are ordinary files written where you choose;
    • 项目包与项目库导出包含任务、诊断证据、场记 Profile 与设置，但不包含全局配置、API Key、OCR 环境或日志； Project packages and library exports carry tasks, diagnostics, slate profiles and settings, but never global configuration, API keys, OCR environments or logs;
    • 导入项目包到本地项目库后，内容会按第 3 条重新加密。 When a package is imported into a local library, its contents are re-encrypted as described in §3.

    10安全措施Security measures

    • 项目库执行路径边界校验，拒绝越界路径与符号链接； The Project Library enforces path-boundary checks and rejects out-of-bounds paths and symlinks;
    • 文件写入使用临时文件与原子替换，项目包导入执行版本、路径与内容校验； Writes use temporary files with atomic replacement; package imports are validated for version, paths and content;
    • 内部 SQLite 在内存中查询并以加密快照原子落盘，避免新增明文数据库日志。 The internal SQLite engine queries in memory and persists as atomic encrypted snapshots, avoiding new plaintext database logs.

    11未成年人Children

    SlateSync 不面向儿童，也不有意收集任何用户（包括儿童）的个人信息。 SlateSync is not directed at children and does not knowingly collect personal information from any user, including children.

    12政策变更Changes to this policy

    数据处理方式变化时，我们会更新本政策和生效日期，并在应用内帮助或发布说明中提示。重大变化会在新版本发布前说明。 When data handling changes, we update this policy and its effective date and note it in in-app Help or release notes. Material changes are stated before a new version ships.
