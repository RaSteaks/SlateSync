隐私政策 Privacy Policy

SlateSync 是一款本地优先的 macOS 应用：识别场记单、校对结构、回填 DaVinci Resolve CSV。本政策说明哪些数据留在你的 Mac、哪些内容会发送给你自己配置的模型服务，以及我们不收集什么。 SlateSync is a local-first macOS app that recognizes camera slates, reviews their structure and backfills DaVinci Resolve CSVs. This policy explains what stays on your Mac, what is sent to model services you configure yourself, and what we never collect.

生效日期：2026 年 9 月 24 日 · 适用于 SlateSync for macOS（1.1 及后续版本） Effective date: September 24, 2026 · Applies to SlateSync for macOS (1.1 and later)

先说结论In short

  • SlateSync 没有账号系统，也不向开发者运营的服务器上传任何数据：没有统计、广告或崩溃上报。 SlateSync has no account system and uploads nothing to developer-operated servers: no analytics, ads or crash reporting.
  • 项目数据保存在本机；项目库内容以 AES-256-GCM 加密，密钥保存在本机登录钥匙串。 Project data stays on your Mac. Library contents are encrypted with AES-256-GCM; the key lives in your Mac's login keychain.
  • 你主动识别时，页面图片、OCR 证据及识别上下文会发送给你配置的模型服务；原始 PDF 文件不会上传。 When you run recognition, page images, OCR evidence and recognition context go to the model service you configured. The original PDF file is not uploaded.
  • 可选的 PaddleOCR 完全在本机运行；Python 环境与模型由你在本机选择和下载。 Optional PaddleOCR runs entirely on your Mac; you choose and download the Python environment and models yourself.

2我们不收集的数据What we don't collect

  • 没有账号、注册或登录，我们不知道你是谁。 No account, registration or sign-in exists — we have no way to know who you are.
  • 没有统计、行为分析、广告 SDK 或崩溃上报；数据不会发送到开发者运营的任何服务器。 No analytics, telemetry, ad SDKs or crash reporting; nothing is sent to developer-operated servers.
  • 我们不出售、出租或共享任何用户数据——因为我们从一开始就没有收到过。 We never sell, rent or share user data — we never receive any in the first place.
  • 模型请求只指向你配置的服务（见第 4 条）；主动安装 PaddleOCR 时还会访问软件源与模型下载服务（见第 5 条）。 Model requests go only to the service you configure (see §4); an optional PaddleOCR installation also contacts package and model sources (see §5).

3本地存储与加密Local storage & encryption

设置、日志与默认项目库位于：Settings, logs and the default Project Library live in:

  • ~/Library/Application Support/SlateSync/（机器设置与日志machine settings and logs）
  • ~/Library/Application Support/Local SlateSync Library/（默认项目库，可在应用中更改位置default Project Library; the location can be changed in the app）

正常启动时，项目库索引、项目设置、任务、诊断证据、场记结构 Profile 与 JSON 快照会自动转换为 AES-256-GCM 加密存储。加密密钥保存在本机 macOS 登录钥匙串，不需要 Apple 开发者账号，也不会同步到 iCloud。 At launch, the library index, project settings, tasks, diagnostic evidence, slate-layout profiles and JSON snapshots are automatically stored encrypted with AES-256-GCM. The key is kept in the local macOS login keychain — no Apple developer account needed, and it never syncs to iCloud.

以下内容不在该加密范围内：原始媒体与媒体缓存、机器级配置和运行日志。该边界保护本地文件内容，不隐藏目录名称，也不能替代整盘加密（如 FileVault）。 Outside this encryption boundary: raw media and media caches, machine-level configuration and run logs. This boundary protects file contents; it does not hide directory names and is not a substitute for full-disk encryption such as FileVault.

若登录钥匙串中的密钥丢失且没有应用内导出的备份，已加密数据无法解密。迁移到新 Mac 请使用应用内导出，不要直接复制内部加密目录。 If the keychain key is lost without an in-app export, encrypted data cannot be decrypted. To move to a new Mac, use in-app export — do not copy the internal encrypted folder directly.

4你配置的第三方 AI 服务Third-party AI services you configure

识别由你自行选择并配置的 OpenAI 兼容视觉服务完成（包括 Base URL、模型与请求并发等，均可在全局设置中修改）。发起识别时，应用会向该地址发送： Recognition is performed by an OpenAI-compatible vision service that you choose and configure (base URL, model, concurrency and more, all editable in Global Settings). When you start a recognition, the app sends to that address:

  • 本地栅格化得到的场记单页面图片； Slate page images rasterized locally;
  • 本地 OCR 证据：识别出的文字、置信度与坐标。 Local OCR evidence: recognized text, confidence and coordinates.
  • 识别上下文：源文件名、你填写的项目自定义提示，以及启用时的场记 CSV 记录、版式提示和输出字段设置。 Recognition context: the source filename, your project custom prompt, and, when used, slate CSV records, layout hints and output-field settings.
  • 如已配置 API Key，认证请求头会将该 Key 发送给所选服务。 If an API key is configured, an authentication header sends it to the selected service.

原始 PDF 文件、完整项目库与其他项目内容不会随识别请求发送；API Key 不写入请求正文，但会用于请求头认证。模型发现（列出可用模型）也只与你配置的服务通信。这些内容一旦发送，其处理受该服务商的隐私政策与条款约束，请在选择服务商时自行确认。 The original PDF file, complete Project Library and other projects' content are not sent with recognition requests. The API key stays out of the request body but is used in the authentication header. Model discovery also talks only to your configured service. Once sent, that content is handled under the provider's own privacy policy and terms — please review them when choosing a provider.

不配置 Provider 时，应用不会为识别产生任何网络请求。 With no provider configured, recognition generates no network requests at all.

5本地 OCROn-device OCR

macOS Vision OCR — 使用系统提供的 Vision 能力，完全在本机运行，数据不离开设备。 Uses the system Vision framework, runs entirely on your Mac, and no data leaves the device.

PaddleOCR（可选optional）— 推理同样完全在本机运行。应用不携带 Python、虚拟环境或模型文件；安装时需要你提供 Python 3.10+ 环境并联网下载依赖与模型（paddlepaddle / paddleocr 固定版本）。该下载由你在本机主动发起，面向相应软件源，SlateSync 不参与其中数据的后续处理。 Inference likewise runs entirely on your Mac. The app bundles no Python, virtualenv or models; installing requires a Python 3.10+ environment you provide and a network download of pinned paddlepaddle / paddleocr dependencies and models. That download is initiated by you on this machine, from the respective package sources; SlateSync does not take part in any downstream handling of it.

6运行日志Run logs

运行日志只保存在本机 ~/Library/Application Support/SlateSync/ 下，按天保留 7 天后清理。日志记录脱敏事件，不包含凭据、原始请求、媒体路径或模型响应正文，也不会被上传。 Run logs are stored only under ~/Library/Application Support/SlateSync/ on your Mac and pruned after 7 days, by day. They record redacted events and never contain credentials, raw requests, media paths or model response bodies, and they are never uploaded.

7API KeyAPI keys

服务商 API Key 保存在本机 macOS 钥匙串中，只有原生应用的数据服务可以读取；UI 不直接访问凭据。Key 不会写入项目包、项目库导出、日志或 Git 仓库，也不会回填显示在设置界面。 Provider API keys are stored in the local macOS keychain, readable only by the native data service; the UI never touches credentials directly. Keys are never written into project packages, library exports, logs or Git, and never echoed back into the settings UI.

8导出与共享Exports & sharing

导出永远由你发起、由你控制去向： Exports are always initiated by you, to destinations you control:

  • 导出的 Resolve CSV 保持通用格式，写入你指定的位置； Exported Resolve CSVs are ordinary files written where you choose;
  • 项目包与项目库导出包含任务、诊断证据、场记 Profile 与设置，但不包含全局配置、API Key、OCR 环境或日志； Project packages and library exports carry tasks, diagnostics, slate profiles and settings, but never global configuration, API keys, OCR environments or logs;
  • 导入项目包到本地项目库后，内容会按第 3 条重新加密。 When a package is imported into a local library, its contents are re-encrypted as described in §3.

9安全措施Security measures

  • 项目库执行路径边界校验，拒绝越界路径与符号链接； The Project Library enforces path-boundary checks and rejects out-of-bounds paths and symlinks;
  • 文件写入使用临时文件与原子替换，项目包导入执行版本、路径与内容校验； Writes use temporary files with atomic replacement; package imports are validated for version, paths and content;
  • 内部 SQLite 在内存中查询并以加密快照原子落盘，避免新增明文数据库日志。 The internal SQLite engine queries in memory and persists as atomic encrypted snapshots, avoiding new plaintext database logs.

10未成年人Children

SlateSync 是面向影视后期专业工作流程的生产力工具，不面向儿童营销，也不有意收集任何用户的个人信息（包括儿童）。 SlateSync is a productivity tool for professional film post-production workflows. It is not marketed to children and does not knowingly collect personal information from any user, including children.

11政策变更Changes to this policy

若数据处理方式发生变化（例如应用引入新的联网功能），我们会更新本政策并修订生效日期，并通过应用内帮助或发布说明提示。重大变化会在新版本发布前明确说明。 If how data is handled ever changes (for example, a new networked feature), we will update this policy and its effective date, and surface it through in-app Help or release notes. Material changes will be called out before a new version ships.
