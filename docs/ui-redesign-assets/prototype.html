从场记单到 Resolve CSV

01 导入
导入场记单

PDF / 图片,本地逐页栅格化;或直接从场记 CSV 生成结果。

→
02 识别
场记识别

Vision / PaddleOCR 提供证据,视觉模型抽取场、镜、次与条次状态。

→
03 校对
人工确认

原稿对照逐条校对;无法确认的字段不会被强行写入。

→
04 对账
Resolve CSV 对账

条号对账、场镜次序检查、完整性告警;可扫描 slate.txt 补充元数据。

→
05 导出
回填导出

仅更新匹配字段,保留原 CSV 的编码、换行与其他内容。
